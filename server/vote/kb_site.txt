【本文档内容】本站页面结构、功能入口、细节功能、开发者信息。站点功能类问题以本文档为唯一依据。

========== 本站主要页面与引导（指路时必须用中文页面名，禁止说 Tools 页 / Workspace 页等英文代号） ==========
- 主页：站点介绍、Logo 与各功能入口；右上角有 中/EN 语言切换、「?」使用帮助、明暗主题切换。
- 培养方案页：有"培养方案 / 教学计划 / 交叉培养指南 / 培养方案解读"四个标签页，可全文搜索；另有课程地图三视图——列表图 / 树状图 / 关系图（关系图可视化先修链路），支持搜索、展开/折叠、固定对象。→ 用户想系统查看培养方案结构、学分要求、课程归属、先修链路时，引导到这里。
- 工作台：核心规划工具。① 按学期录入选课历史，支持自定义课程；② 课程目录可按课组 / 开课学期 / 模块 / A、B 课组筛选与搜索，开启"推荐"开关后按你的历史智能排序并给出蓝条提示；③ 预选下学期课程，自动校验学分上下限、强先修缺失、选课组限选与历史重复，诊断面板会汇总问题；④ 支持选课数据导出（JSON 文件），导入分两路——「导入本地数据」上传 JSON 文件（可选合并或覆盖）、「导入云端方案」读取账号的云端方案。→ 用户要记录已修课程、规划某学期选课、或想完整浏览/筛选课程清单时，引导到这里。
- 综合工具页：三个标签。①"学位评定"：导入选课数据后自动计算七个学位轨道（AE/EM/PE/IE/SE/CE/CED）的获取进度，并提供模块级详细查询（I类基础加强·模块1-3 / 软件工程II类·模块4-8 / 工业工程III类·模块9-13）与跨类达标检查；CE 轨道卡可手动指定主修模块、CED 轨道卡可手动指定专业一/专业二（均可撤销），指定后进度按指定口径计算。②"AI推荐助手"：即本助手；③"课程评价"：账号系统规划中，目前仅有设计投票。→ 用户关心毕业进度、学位评定、各轨道完成度对比时，引导到"学位评定"标签。
- 关于我们页：站点简介与开发缘起（笃实智囊团项目）、开发者寄语、联系方式（开发者校园邮箱）、公众号文章链接，以及"问题反馈"入口（共享文档，欢迎提 Bug 与建议）。→ 用户问站点本身、想联系开发者或反馈问题时，引导到这里。

========== 站内细节功能（用户问到时简要说明入口） ==========
- 术语提醒：用户说"邮件/信封"时，指的是站内消息功能（信封图标），不是开发者的电子邮箱；开发者联系方式在"关于我们"页。
- 使用教程：导航栏右侧的「?」帮助按钮打开"使用帮助"面板，内有 导入历史/规划下学期/智能推荐/综合工具/培养方案 五条速查说明，并可"重新观看引导"；新用户首次访问会自动弹出分步功能引导（步骤较多，移动端建议到 PC 端观看）。
- 站内消息：桌面端导航栏 logo 右侧的信封图标，收网站更新与网站声明公告，显示未读数、可"全部已读"，7 天内的消息带"新"标记；移动端在底部导航的顶栏里。
- 语言切换：导航栏与主页右上角的"中/EN"开关，全站中英双语一键切换。
- 账号与云端方案：右上角头像入口，可用清华邮箱（@mails.tsinghua.edu.cn）注册/登录，站内显示名为邮箱前缀（社交场景可用昵称，不实名、邮箱不公开）。登录后可把当前培养方案数据存为"云端方案"（云端保存完整快照，可多设备同步，也可复制多套方案）；账号入口内可切换培养方案年级（字班）。未登录时数据仅保存在本地浏览器。
- 明暗主题切换：导航栏与主页右上角的日/夜图标。
- 当前学期选择器：导航栏"当前学期"下拉，决定工作台可用的学期列表。
- 课程地图显示上限：列表图/树状图有"同时可见课程上限"（默认 60，滑条可调，最低 20），为保障流畅度而设；"展开全部匹配"超出上限时会弹窗询问临时扩大或仅展开上限内，用顶部搜索可精准定位而绕开上限。推荐值：60~80 适合局部浏览；设为 142 可恰好完整展示全部交叉模块（专业模块）课程。

网站简介：
    本网站旨在帮助笃实书院的同学更从容地进行选课规划，项目构想源自 2025 年秋季启动的「笃实智囊团」项目。
    网站目前仍处于持续开发阶段，难免存在疏漏与错误，恳请大家多多指正。
    更多背景介绍可参阅公众号文章：https://mp.weixin.qq.com/s/1NaZNrRB8M2MuhrgbaV3pw

开发者寄语：
    每到选课季，总能看见同学们在繁多的课程之间反复权衡、难以抉择，我深深懂得这份纠结与焦虑。尤其步入大二，各类专业课接踵而至，不少人都会陷入找不到未来方向的迷茫。彼时的我也曾暗自期许，如果能有一款实用的工具，帮大家梳理清晰学业规划，该有多好……
    2025 年秋季，我响应王琛老师的号召，加入了「笃实智囊团」。刚加入团队时，我的工程实践经验尚且不足，开发能力也十分有限。当时的我们选择了使用思维导图的方式呈现培养方案，但我们发现多种课组间的交叉融合关系需要用复杂的线条展示出来时，我意识到：还是需要用代码的方式去呈现它！
    正是这段宝贵的经历，让我萌生了发起本项目的想法。正如本项目的名称OfCourses那样，我希望大家选课时也能有股Of Course的果断。我希望尽自己的一份力量，缓解同学们选课时的犹豫困惑，拨开大家对于未来发展方向的迷雾。
    感谢王琛老师，让我能有此想法与契机去为书院的大家做点事情。感谢同班王德宇同学，在网站搭建初期为我提供了宝贵的架构思路。感谢人工智能技术，在AI工具的加持下，开发工作变得更加容易：在培养方案的数据提取、格式转换等工作中，它为项目推进提供了至关重要的助力。
    目前网站还预留了不少待开发的后续功能，仍需要通过 UI 优化与新功能迭代逐步完善。如果你在使用过程中发现未曾留意到的 Bug，或是有任何优化改进的建议，无论大小，每一条反馈都能让网站变得更加稳定好用。我们十分期待听到你的声音，欢迎点击下方「问题反馈」链接，前往共享文档留下你的宝贵意见。
